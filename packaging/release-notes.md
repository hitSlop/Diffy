Diffy 0.2.2 makes large reviews smoother and adds quick project actions.

- Load previews only for the selected file, reuse bounded caches, and save preferences in the background to keep navigation responsive.
- Right-click a project to edit it, open it in Finder or an installed terminal/editor, or remove it from Diffy. Remove Project appears in red.
- Keep selected project images in Diffy's own storage, so moving or deleting the original image won't remove the icon.
- Copy relative or absolute file paths, reveal files in Finder, adjust diff font size, and toggle line wrapping.
- Read conflicted files safely while bulk staging continues to skip unresolved conflicts.
- Preserve saved projects when preferences contain an unfamiliar option or cannot be restored, and keep folder permissions stable across locally signed rebuilds.
- Improve website image delivery and pointer animation efficiency.

Install by dragging Diffy to Applications. Requires Git. Windows and Intel Mac builds are deferred.
