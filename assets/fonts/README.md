# Commit Mono 1.143

Unmodified upstream OTF files copied from Eigil Nikolajsen's Commit Mono source:

- `CommitMonoV143-400Regular.otf`: Regular, weight 400
- `CommitMonoV143-500Regular.otf`: Medium, weight 500

Source: https://github.com/eigilnikolajsen/commit-mono/tree/main/src/fonts/fontlab
Website: https://commitmono.com/
License: SIL Open Font License 1.1; see `LICENSE`.

GPUI registers these font bytes at startup under their native family name,
`CommitMonoV143`. Differ disables the `calt` and `liga` OpenType features.
